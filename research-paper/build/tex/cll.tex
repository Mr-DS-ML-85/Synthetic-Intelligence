\section{Constructive Language Locking (CLL): Separating Cognitive
Freedom from Linguistic
Protocol}\label{constructive-language-locking-cll-separating-cognitive-freedom-from-linguistic-protocol}

\textbf{Irfan Mahir} \emph{Independent Researcher, Dhaka, Bangladesh}
irfan@furylogic.com

\begin{quote}
\emph{``Grammar is not a law of nature awaiting discovery. It is a
protocol two people agreed to. Confusing the two is why physics-based
language generation has failed.''}
\end{quote}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{Abstract}\label{abstract}

Wave-based cognitive substrates have repeatedly failed to produce
grammatical natural language, and the field's response has been to
abandon the mechanical problem in favour of a statistical one:
\(P(w_n \mid w_1 \ldots w_{n-1})\). We argue this was a false dilemma
created by a category error. Cognition and language are different kinds
of process --- one \emph{discovers}, the other \emph{transmits} --- and
attempting to derive grammar from field dynamics conflates a
communication protocol with a physical phenomenon. We propose
\textbf{Constructive Language Locking (CLL)}: the cognitive substrate
remains entirely unconstrained and constructive, while surface
realisation is delegated to \emph{isolated language clusters} holding
fixed, deterministic grammatical rules. The core loses no flexibility
because no grammar rule ever enters it; the output gains exact,
non-hallucinating surface form because nothing is sampled. We show the
architecture emits one cognitive state into English, Bengali and
Banglish from a single triple, at \(O(1)\) lookup cost, with zero
learned parameters.

\subsubsection{1.2 Why This Killed Physics-Based
Generation}\label{why-this-killed-physics-based-generation}

Earlier work in this lineage (\texttt{synthetic-intelligence.md} §5.4b,
\texttt{mrs.md}) attempted to derive word ordering from field dynamics:
syntax slots with fixed natural frequencies, phase-locked readout, gauge
offsets enforcing subject-before-object. The concept-level ordering
partially succeeded. The \emph{byte}-level emission babbled.

The diagnosis was repeatedly treated as a tuning problem. It was not.
Asking a resonance field to discover that English uses articles is
asking it to derive a convention from a phenomenon. There is no gradient
to follow because there is no fact of the matter.

\textbf{The field ran to language models for the same reason.} The
statistical shortcut is not a theory of language production; it is what
remains once the mechanical problem is abandoned. A next-token
distribution requires no account of \emph{why} one word follows another,
only a count of how often it did. It works spectacularly, and it
forecloses the question.

CLL claims the mechanical route was never seriously attempted because
the problem was mis-stated, not because it is closed.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{2. The Locking Principle}\label{the-locking-principle}

\textbf{Definition (Constructive Language Locking).} A cognitive
architecture satisfies CLL when:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Core freedom.} No grammatical rule appears anywhere in the
  cognitive substrate. Its dynamics, novelty mechanisms, and structural
  operations are identical whether the output language is English,
  Bengali, or none.
\item
  \textbf{Protocol determinism.} Surface realisation is a total function
  from (cognitive state, language cluster) to string. The same input
  always yields byte-identical output. Nothing is sampled.
\item
  \textbf{Isolation.} Language clusters may be added, removed, or
  replaced without modifying the core. Their number does not affect
  cognitive capability.
\end{enumerate}

The name records the asymmetry: cognition stays \textbf{constructive}
(free to build), while language is \textbf{locked} (fixed to a
protocol).

\textbf{Corollary (No cognitive degradation).} Because (1) forbids
grammar in the core, adding a language cluster cannot reduce cognitive
flexibility. This is a structural guarantee, not an empirical claim.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{3. Architecture}\label{architecture}

\begin{verbatim}
   [ Core SI Physics Substrate ]
     resonance, phase-locking, fission, L6-A bridging,
     thermodynamic discovery, oracle validation
                  |
                  |  emits raw concept triples
                  |  (subject, relation, object)
                  v
   [ Isolated Language Clusters ]
     +- English   : SVO grid, articles, 3sg agreement
     +- Bengali   : SOV grid, no articles, danda terminator
     +- Banglish  : SOV grid, Latin script, strict transliteration
                  |
                  v
          human-readable stream
\end{verbatim}

The interface between the layers is deliberately narrow: a triple of
graph labels plus a relation identifier. Nothing linguistic crosses
upward, and nothing cognitive crosses downward.

\subsubsection{3.2 Realisation}\label{realisation}

Given triple \((s, r, o)\) and cluster \(L\):

\[
\text{realise}_L(s,r,o) = \Pi_L\bigl(\lambda_L(s),\; \rho_L(r),\; \delta_L(r, o)\bigr)
\]

where \(\lambda_L\) is concept surface form (transliteration if any),
\(\rho_L\) is relation lexicalisation, \(\delta_L\) applies determiner
policy conditioned on the \emph{construction} \(r\), and \(\Pi_L\)
permutes by word order. Every component is a table lookup or a fixed
string operation. The function is total and deterministic.

\subsection{4. A Defect That Testing Disproved
Immediately}\label{a-defect-that-testing-disproved-immediately}

The first implementation treated determiner insertion as a
\textbf{global language property} --- ``English uses articles'' --- and
produced:

\begin{quote}
\emph{``Biology is a the science.''}
\end{quote}

Whether an object takes a determiner is not a property of the language.
It belongs to the \textbf{construction}: \texttt{is\_a} already supplies
its own article; proper nouns take none. The policy is now a
per-relation flag.

This is recorded because it establishes the shape of all remaining work
in this layer. Real grammar exceeds word order, and each additional rule
is discovered by \emph{testing against a speaker's judgement}, not by
gradient descent. Every one is deterministic data.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{5. Transliteration as Strict
Relation}\label{transliteration-as-strict-relation}

Code-switching is where language models fail most visibly and CLL
succeeds most cleanly. The mapping

\[
\texttt{tumi} \;\xleftrightarrow{\;\text{REL\_PHONETIC\_EQUIV}\;}\; \texttt{তুমি}
\]

is a \textbf{strict static relation}, not a probable correspondence.
There is no distribution over spellings, so there is no drift. A
language model generating Banglish must sample each character sequence
and will produce \emph{tumi}, \emph{tomi}, \emph{tumii} across a single
document. CLL cannot, because nothing is sampled.

This generalises to dialect: Sylheti, Chittagonian and standard Bengali
differ in phonotactic mapping while sharing cognitive content. Swapping
the transliteration table swaps the dialect. The thought is unchanged.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{6. Cost Accounting}\label{cost-accounting}

CLL introduces \textbf{no hidden cost} and must be honest about the cost
it does introduce.

The Translation Capacity Lemma (\texttt{synthetic-intelligence.md} §3.1)

adds:

\subsection{8. What Remains Open}\label{what-remains-open}

CLL solves \emph{protocol}. It does not solve \emph{morphological
productivity}.

\textbf{Solved.} Word order, determiner policy, relation lexicalisation,
script and transliteration, terminator conventions, dialect swap.

\textbf{Deterministic but unwritten.} Subject-verb agreement
(\emph{studies}, not \emph{study}); pluralisation; Bengali verb
conjugation by person and honorific (তুমি / আপনি / তুই); case marking
under free word order; multi-triple discourse with pronoun resolution.
All are tables. None needs ML. They are labour, not research.

\textbf{Genuinely open.} Producing the bytes of a word \textbf{not in
the lexicon} --- inflecting an unseen stem, coining a compound. This is
the residual of the emission problem (\texttt{synthetic-intelligence.md}
§8.5), and CLL narrows it rather than solving it: for any word already
in Layer 3, no byte synthesis is required at all. The open problem is
morphological \emph{productivity}, not speech.

\textbf{Not attempted.} Prosody, register, politeness gradation beyond
pronoun choice, and anything requiring modelling the listener.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{9. Failure Modes}\label{failure-modes}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Protocol drift from reality.} A hand-written grammar table can
  be simply wrong about the language. There is no gradient to correct it
  --- only a native speaker. This is a genuine disadvantage relative to
  corpus-fitted models, and the correct mitigation is a held-out
  judgement set per language, not more rules.
\item
  \textbf{Coverage cliff.} A relation with no lexicalisation entry falls
  back to rendering its identifier. The output stays intelligible but
  degrades visibly. This is preferable to inventing a form, but it is a
  cliff rather than a slope.
\item
  \textbf{The template ceiling.} Single-triple realisation cannot
  produce subordination, relative clauses, or discourse cohesion.
  Extending to multi-triple output requires a discourse layer that does
  not yet exist, and it is not obvious that it remains purely tabular.
\item
  \textbf{False economy on free-word-order languages.} Bengali permits
  reordering because case marking carries role. A fixed SOV template is
  an approximation that will read stiffly, and the fix is case
  morphology --- item (2) of §8, not a new mechanism.
\end{enumerate}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\subsection{10. Summary}\label{summary}

Physics-based language generation failed because it asked a resonance
field to discover a convention. Constructive Language Locking separates
the two: cognition remains fully constructive and unconstrained, while
surface realisation is a deterministic protocol held in isolated,
swappable language clusters.

The core loses nothing --- a structural guarantee, since no grammar rule
enters it. The output gains exactness that sampling architectures cannot
have. And the mechanism costs a table per language against a GPU forward
pass per sentence.

The remaining hard problem is smaller and better specified than before:
not \emph{how does a field speak}, but \emph{how does a field inflect a
word it has never seen}.
